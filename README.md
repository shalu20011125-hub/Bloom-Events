# Bloom Events – Flower Decoration & Event Management Website

A modern, elegant, fully responsive **Flower Decoration & Event Management Website** built with React.js, Tailwind CSS, and Lucide React.

## 🌸 Brand Overview & Theme

- **Business Name**: Bloom Events
- **Aesthetic**: Premium floral artistry, luxury wedding mandaps, editorial romanticism
- **Color Palette**:
  - Soft Pink (`#FFF5F6`, `#FAF0F2`, `#B85C6D`)
  - Warm White & Cream (`#FFFDFB`, `#FAF6F3`, `#EDE4DE`)
  - Elegant Gold (`#D4AF37`, `#8C6D1F`, `#F4E3BD`)
  - Deep Botanical Charcoal (`#2C2422`, `#4A3E3D`)
- **Typography**: Cormorant Garamond for display titles + Plus Jakarta Sans for body prose.

---

## 📄 Pages & Architecture

1. **Home Page (`/`)**
   - Sticky top navigation with brand logo and mobile menu
   - Hero section featuring an opulent wedding stage with flowers and dual CTAs: *Explore Our Services* and *Book Your Event*
   - Event category cards (Wedding, Birthday, Engagement, Baby Shower, Corporate Events)
   - Popular decoration designs with starting sample prices
   - About Bloom Events company highlights with trust metrics
   - Sample client reviews and testimonial cards
   - Comprehensive footer with sample studio contacts and social links

2. **Services & Gallery (`/services`)**
   - Service cards for Wedding, Birthday, Engagement, Baby Shower, and Corporate decor
   - Interactive floral design gallery with live category filtering
   - Lightbox modal preview for high-resolution floral details
   - 3 Signature decoration packages (Basic, Premium, and Luxury) with itemized inclusions and direct booking links

3. **Book an Event (`/book`)**
   - Clean, validated enquiry consultation form (Full Name, Email, Phone, Event Type, Date, Venue, Package, Budget, and Vision)
   - Frontend validation with informative error messages
   - Frontend-only submission confirmation with a summary of the prepared enquiry
   - Clear disclosure stating the form is an enquiry demonstration that does not store data or charge payments
   - Step-by-step 4-stage event booking timeline

4. **About Us & Contact (`/about`)**
   - Brand narrative: "We Bring Your Beautiful Moments to Life"
   - Mission statement and four core values
   - Meet Our Creative Team cards (Creative Director, Event Planner, Production Lead)
   - "Why Choose Us" 4-point standard
   - Direct studio contact information (sample phone, email, address, and operating hours)
   - Interactive validated contact inquiry form with live confirmation feedback

## 🚀 Running the Project

To install dependencies:
```bash
npm install
```

To run the development server:
```bash
npm run dev
```

To build for production:
```bash
npm run build
```
